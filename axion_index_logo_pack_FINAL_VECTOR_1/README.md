# Axion Index — Logo Pack (Production Vector)

All assets are TRUE VECTOR (outlined paths / polygons). No raster, no embedded PNG,
no gradient, no glow. Fully recolourable and scalable.

## Colours (locked)
- Gold (primary):   #C9A24A
- Dim tagline gold: #8A7338
- Black:            #0A0A0B
- White (knockout): #F4EFE6

## Files

### Wordmark (header / nav / documents)
- svg/axion-index-wordmark-gold.svg
- svg/axion-index-wordmark-white.svg
- svg/axion-index-wordmark-black.svg
Outlined geometric face (Jost, closest match to approved renders — see note below).

### AI monogram (favicon / social / app icon / small use)
- svg/axion-ai-mark-gold-on-black.svg
- svg/axion-ai-mark-black-on-gold.svg
- svg/axion-ai-mark-gold-transparent.svg
- favicon.svg  + png/favicon-{16,24,32,48,64,128,180,192,512}.png
Construction: apex-A + separate SLANTING \ I-stroke, parallel to the A's right leg (approved AI mark). Holds at 16px.

### Lockups
- svg/axion-index-lockup-gold-on-black.svg            (square: mark / wordmark / 2-line tagline) — footer, deck covers
- svg/axion-index-horizontal-ai-full-lockup-on-black.svg  (mark | wordmark | full-width tagline) — OG, LinkedIn, launch
- svg/axion-index-horizontal-ai-no-tagline.svg            (no tagline) — product/report header strips

## Website usage
- Header = wordmark only (no tagline, no mark)
- Footer = square lockup with muted tagline
- Favicon / social avatar = AI monogram
- OG / LinkedIn / WhatsApp = horizontal full lockup (export to PNG/JPG — SVG won't preview on social)
- Product / PDF / report header = horizontal no-tagline

## Rules
- Flat gold only. No gradient, glow, bevel, shadow, emboss, shine.
- Do not stretch or distort. Maintain clear space (>= one stroke width all sides).
- Tagline always muted (#8A7338), never equal brightness to wordmark.
- Do not use the earlier slash/X or polygon-screenshot marks.

## IMPORTANT — typeface note
The wordmark here is outlined in **Jost** (geometric, Futura-lineage; closest freely-
licensed match to your approved renders). It is NOT glyph-identical to the original
render's face. If you have the original typeface name or source file, the wordmark
can be rebuilt glyph-exact — the monogram and all layout/colour are already final.
